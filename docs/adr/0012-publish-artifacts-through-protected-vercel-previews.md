# Publish remote Artifacts through protected Vercel previews

Phase 9 uses local loopback viewing by default and one optional Vercel preview adapter for sanitized static remote publication. Interactive and live HTML remain local-only because CSP does not restrict top-level navigation. The adapter uploads only generated integrity-manifest bundles to a dedicated non-Git project, verifies preview authentication before upload, refuses production aliases, requires exact direct-user confirmation, and supports expiring revocable share capabilities plus deployment deletion. GitHub Gists/Pages and Cloudflare Pages were rejected because private access is not a safe default; a custom internet-facing artifact host was rejected because it would add identity, storage, and security operations beyond this phase. Vercel deletion stops serving but does not promise immediate physical erasure, so Revocation, Deletion, and Erasure remain distinct.
